# Сайт свадебного фотографа

Одностраничник на чистом HTML, без внешних CDN (шрифты и фото лежат внутри), поэтому нормально открывается из РФ.

## Обновить фото
    pip install pillow pillow-heif
    python compress.py "путь/к/исходникам/Свадьба 1" img --prefix story1

## Где менять текст
Все места для замены в index.html помечены комментарием 🚨 и квадратными скобками [ ].
